# SOULPAL

GitHub-ready single-file prototype based on the SOULPAL visual direction.

- Warm pastel UI
- Playfair + DM Sans typography
- Personalized onboarding
- Interests included in onboarding, not a separate fifth screen
- No Come Follow Me / denomination-specific feature
- Home, Study, Talk, Discover, Journal, Progress, Themes and Settings
- Local browser storage for demo profile and journal

## Publish
Upload `index.html` to a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).
